この挙動は動的にフォームの中身が変わったりする時などで困ってしまうので、中の要素が変わった時も位置調整するように実装しました。以下のgifアニメのように画面外に出ないようになります。

![](/images/auto-reposition-popover/auto-reposition-popover.gif)

最終的にPopoverをラップして普段通り使うことができるように汎用的にすることが出来たので、備忘録として記事にまとめたいと思います。

## MUI Popoverで中の要素のサイズが変わった時の位置調整方法

まずChatGPTに軽く聞いたところ、Popoverには `updatePosition`というメソッドが提供されているため、これを内部の要素のサイズが変わったときに実行すると良さそうです。

![](/images/auto-reposition-popover/update-position-api.png)

![](/images/auto-reposition-popover/auto-reposition-by-resize-observer.png)

しかしこれを毎回設定するのは手間です。そこで`WrappedPopover`というコンポーネントを作って、位置調整ロジックを内部で実装するように調整します。リサイズ検知の要素はPopoverの中でPaperコンポーネントが使われていてそこのrefを使いました。そして内部で設定したrefによって外から指定出来なくなるように、`useForkRef`で統合したrefを渡すようにしました。これらを考慮して実装すると最終的に以下のコードになりました。

```tsx:要素のサイズが変わった時に位置調整されるようにしたPopoverコンポーネント
import type {
  PaperProps,
  PopoverActions,
  PopoverProps as MuiPopoverProps,
} from '@mui/material';
import { Popover as MuiPopover, useForkRef } from '@mui/material';
import type { FC, ReactNode } from 'react';
import { useRef, useCallback } from 'react';

type OverrideType<T, Override extends Partial<Record<keyof T, any>>> = {
  [K in keyof T]: K extends keyof Override ? Override[K] : T[K];
};

export type WrappedPopoverProps = OverrideType<
  MuiPopoverProps,
  {
    slotProps: OverrideType<
      Required<MuiPopoverProps>['slotProps'],
      {
        // SlotComponentProps<typeof Paper, {}, {}>だとrefの型が合わないため、PaperPropsのrefを上書きする
        paper: Partial<PaperProps>;
      }
    >;
  }
>;

/**
 * childrenのキャッシュやResizeObserverを使った位置の更新など、MUIのPopoverに機能を追加したコンポーネント
 */
export const WrappedPopover: FC<WrappedPopoverProps> = ({
  action: propActionRef,
  slotProps,
  children,
  ...restProps
}) => {
  /** Popoverの位置を更新するためのアクション */
  const actionRef = useRef<PopoverActions>(null);
  const mergedActionRef = useForkRef(actionRef, propActionRef);

  const { paper: paperSlotProps, ...restSlotProps } = slotProps ?? {};
  // Paperコンポーネントのrefを取得して、サイズが変わったときにPopoverの位置を更新する
  const paperRef = useCallback((element: HTMLElement | null) => {
    const observer = new ResizeObserver(() => {
      actionRef.current?.updatePosition();
    });
    observer.observe(element);

    return () => {
      observer.disconnect();
    };
  }, []);
  const mergedPaperRef = useForkRef(paperRef, paperSlotProps?.ref);

  return (
    <MuiPopover
      action={mergedActionRef}
      slotProps={{
        paper: {
          ref: mergedPaperRef,
          ...paperSlotProps,
        },
        ...restSlotProps,
      }}
      {...restProps}
    >
      {children}
    </MuiPopover>
  );
};
```

あとは`Popover`の代わりにこの`WrappedPopover`を呼ぶだけで自動で位置調整されるようになります✨

## その他

### Popoverが閉じられるまでコンテンツをキャッシュして中身を維持する方法

本題とは少し逸れますが、今回の検証コードでは以下のように非表示の時はコンテンツの中身が空になるように書いています。これによって閉じる時に徐々に小さくなるアニメーションが見れず一瞬で消えてしまうような見え方になってしまいます。

```tsx
const App: FC = () => {
  const [textList, setTextList] = useState(() => {
    return [
      '1つ目の初期テキスト',
      '2つ目の初期テキスト',
      '3つ目の初期テキスト',
    ];
  });
  const [editingTextIndex, setEditingTextIndex] = useState<number | null>(null);
  const [anchorEl, setAnchorEl] = useState<HTMLElement | null>(null);

  const closePopover = () => {
    setEditingTextIndex(null);
    setAnchorEl(null);
  };

  return (
    <Box>
      <Popover
        open={anchorEl != null}
        anchorEl={anchorEl}
        anchorOrigin={{ vertical: 'bottom', horizontal: 'right' }}
        transformOrigin={{ vertical: 'top', horizontal: 'right' }}
        onClose={() => {
          closePopover();
        }}
      >
        {/* Popoverを閉じるときにeditingTextIndexをnullにするため、クローズアニメーション中に中身が空になる */}
        {editingTextIndex != null && (
          <TextForm
            initialText={textList[editingTextIndex]}
            onEdit={(newText) => {
              setTextList([
                ...textList.slice(0, editingTextIndex),
                newText,
                ...textList.slice(editingTextIndex + 1),
              ]);
              closePopover();
            }}
            onCancel={() => {
              closePopover();
            }}
          />
        )}
      </Popover>
    </Box>
  )
}
```

![](/images/auto-reposition-popover/vanish-content.gif)

この問題を回避するには以下の記事に書いてある通りchildrenをキャッシュしておくと良いので、その機能も追加しておきました。

https://zenn.dev/numa_san/articles/7f37c975f46ef8

```diff tsx:クローズアニメーション中に中身が消えないようにchildrenをキャッシュする
 /**
  * childrenのキャッシュやResizeObserverを使った位置の更新など、MUIのPopoverに機能を追加したコンポーネント
  */
 export const WrappedPopover: FC<WrappedPopoverProps> = ({
+  open,
   action: propActionRef,
   slotProps,
   children,
   ...restProps
 }) => {
+  /**
+   * 子要素のキャッシュデータ
+   * @note 詳細データがnullの時に非表示するみたいな実装の際、クローズアニメーション中に要素が消えてしまわないためのキャッシュ
+   */
+  const cachedChildrenRef = useRef<ReactNode>(null);
+  // 開いている時だけ子要素を更新する
+  if (open) {
+    cachedChildrenRef.current = children;
+  }
 
   // 差分がないため省略
 
   return (
     <MuiPopover
       action={mergedActionRef}
+      open={open}
       slotProps={{
         paper: {
           ref: mergedPaperRef,
           ...paperSlotProps,
         },
         ...restSlotProps,
       }}
       {...restProps}
     >
-      {children}
+      {cachedChildrenRef.current}
     </MuiPopover>
   );
 };
```

これを書くと以下のgifアニメのように自然なクローズアニメーションになります。
