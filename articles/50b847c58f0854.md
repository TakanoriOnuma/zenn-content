## 始めに

編集を気軽に行えるように、対象のフィールドのみ編集ボタンを押すことでその場で編集状態になって編集ができる、いわゆるインライン編集と呼ばれるものがあります。
具体的には以下のようなGifアニメのようなもので、編集アイコンを押してテキストフィールドが出て、入力後保存を押すことで編集結果が表示されます。

![](/images/customizable-editable-fields/example-editable-fields.gif)

簡単な編集においては便利なUIである一方で、実装面では以下のような細かいケアを考えると結構面倒です。

- 編集直後にAPIから取得した古いデータを表示しないようにする
- 配置する場所によって表示に関する微調整

この辺の課題をクリアするために、ベースとなるコンポーネントにロジック周りを集約させ、表示部分を全てrenderPropsでカスタマイズ可能な状態にすることでかなり柔軟性の高いものを作ることができたので、備忘録として記事にまとめたいと思います。

## 拡張性の高いインライン編集UIの実装

### インライン編集UIの土台の作成

まず大枠の構成として、通常時と編集モードの時に表示される要素はスクショのように3種類に分けました。ラベル部分は通常時と編集モードどちらでも表示しており、`isEditMode`というフラグで出し分けます。

![](/images/customizable-editable-fields/editable-fields-normal.png)

![](/images/customizable-editable-fields/editable-fields-edit-mode.png)

これらの要素をそれぞれrenderPropsで描画できるようにします。ラベル、コンテンツ、フォームどの要素でも同じパラメータを参照できるように先に型を定義すると以下のようになります。

```tsx:renderPropsに指定する型
export type RenderEditableFieldParams<T> = {
  /** 更新処理中か */
  isUpdating?: boolean;
  /** 編集モードか */
  isEditMode: boolean;
  /** フィールドラベル */
  label: string;
  /** テキストの値 */
  value: T;
  /** 編集不可か */
  disabled?: boolean;
};
export type RenderEditableFieldActions<T> = {
  /**
   * 編集を開始する
   */
  editStart: () => void;
  /**
   * 編集を終了する
   */
  editEnd: () => void;
  /**
   * 送信する
   * @param newValue - 新しい値
   */
  submit: (newValue: T) => void;
};

export type RenderEditableFieldHandler<T> = (
  params: RenderEditableFieldParams<T>,
  actions: RenderEditableFieldActions<T>
) => ReactNode;
```

この型を元にまずはラベルの描画部分を定義すると以下のようになります。こちらは基本変わらないと思うため、defaultというprefixをつけたrenderメソッドになります。最初に見せたGifアニメのように、隣に編集アイコンが置いてあり、編集時は非表示になるシンプルなものになります。

```tsx:ラベル部分の描画メソッド
import { Typography, Stack } from "@mui/material";

export const defaultRenderEditableFieldLabel: RenderEditableFieldHandler<
  any
> = ({ label, isEditMode, disabled }, { editStart }) => {
  return (
    <Stack sx={{ alignItems: "center" }} direction="row" spacing={0.5}>
      <Typography sx={{ fontWeight: "bold" }}>{label}</Typography>
      {!isEditMode && (
        <IconButton
          aria-label={`${label}を編集`}
          size="small"
          disabled={disabled}
          onClick={editStart}
        >
          <EditIcon fontSize="small" />
        </IconButton>
      )}
    </Stack>
  );
};
```

これらを使って雛形となる`EditableField`コンポーネントを実装すると以下のようになります。まずは土台なので各renderPropsに渡すパラメータを用意して流すだけのシンプルなものになっています。更新時の値の保持については後で追記するので一旦今はありません。
`renderLabel`については基本変わらないと思うので`defaultRenderEditableFieldLabel`をデフォルト引数に取っております。他の`renderContent`や`renderForm`については値によって変わるため必須で指定してもらう形にしてます。

```tsx:インライン編集UIの土台コンポーネントの作成
import { useState } from "react";

export type EditableFieldProps<T> = Omit<
  RenderEditableFieldParams<T>,
  "isUpdating"
> & {
  /**
   * 値を更新するハンドラ
   * @param newValue - 更新する値
   */
  updateHandler: (newValue: T) => Promise<void> | void;
  /**
   * 編集を開始する
   */
  onEditStart: () => void;
  /**
   * 編集を終了する
   */
  onEditEnd: () => void;
  /**
   * フィールドラベルの描画
   */
  renderLabel?: RenderEditableFieldHandler<T>;
  /**
   * フィールドコンテンツの描画
   */
  renderContent: RenderEditableFieldHandler<T>;
  /**
   * 編集フォームの描画
   */
  renderForm: RenderEditableFieldHandler<T>;
}

export const EditableField = function <T>({
  isEditMode,
  label,
  value,
  disabled,
  updateHandler,
  onEditStart,
  onEditEnd,
  renderLabel = defaultRenderEditableFieldLabel,
  renderContent,
  renderForm,
}: EditableFieldProps<T>) {
  // 更新中か
  const [isUpdating, setIsUpdating] = useState(false);

  const params: RenderEditableFieldParams<T> = {
    isUpdating,
    isEditMode,
    label,
    value,
    disabled,
  };
  const actions: RenderEditableFieldActions<T> = {
    editStart: onEditStart,
    editEnd: onEditEnd,
    submit: async (newValue: T) => {
      setIsUpdating(true);
      try {
        await updateHandler(newValue);
        onEditEnd();
      } finally {
        setIsUpdating(false);
      }
    },
  };

  return (
    <Stack spacing={0.5}>
      {renderLabel(params, actions)}
      {isEditMode && !disabled
        ? renderForm(params, actions)
        : renderContent(params, actions)}
    </Stack>
  );
};
```

### テキスト用のインライン編集UIの実装

前セクションで作成した`EditableField`を元にテキスト用のインライン編集UIを作っていきます。
まずはコンテンツ部分のコンポーネントを用意します。renderPropsと引数を合わせても良いのですが、使わないパラメータの方が多いので独立したもので作成しています。次で説明するフォームの実装を見ると分かりますが、複数行の入力を可能にするため`whiteSpace: 'pre-wrap'`で改行表示対応をしています。文字が入力されていない場合は分かりやすいようにグレーで`(未入力)`と表示します。

```tsx:テキスト用のコンテンツ表示コンポーネント
import { Typography } from "@mui/material";

export const EditableTextFieldContent: FC<{ value: string }> = ({ value }) => {
  return (
    <Typography
      sx={{ whiteSpace: "pre-wrap" }}
      color={value ? undefined : "textSecondary"}
    >
      {value || "(未入力)"}
    </Typography>
  );
};
```

続いてフォーム部分を用意します。フォーム部分の送信とキャンセルボタンは他のフォームでも共通だと思うのでまずは`EditableFieldFormLayout`というコンポーネントで枠を用意して、その中でテキスト用のフォームを作成します。後で複数行用の入力UIも使うので`multiline`オプションも渡せるようにしておきます。

```tsx:フォームのレイアウト部分
import { Button, Stack } from "@mui/material";
import type { FC, ReactNode } from "react";

export type EditableFieldFormLayoutProps = {
  /** 更新中か */
  isUpdating?: boolean;
  /** 送信ボタンクリック時 */
  onClickSubmit: () => void;
  /** キャンセルボタンクリック時 */
  onClickCancel: () => void;
  /** フォームの中身 */
  children: ReactNode;
};

export const EditableFieldFormLayout: FC<EditableFieldFormLayoutProps> = ({
  isUpdating,
  onClickSubmit,
  onClickCancel,
  children,
}) => {
  return (
    <Stack spacing={1}>
      {children}
      <Stack sx={{ justifyContent: "flex-end" }} direction="row" spacing={2}>
        <Button
          variant="outlined"
          color="primary"
          disabled={isUpdating}
          onClick={onClickCancel}
        >
          キャンセル
        </Button>
        <Button
          variant="contained"
          color="primary"
          loading={isUpdating}
          onClick={onClickSubmit}
        >
          保存
        </Button>
      </Stack>
    </Stack>
  );
};
```

```tsx:テキスト用のフォームコンポーネント
import { TextField, Typography } from "@mui/material";

export const EditableTextFieldForm: FC<{
  isUpdating?: boolean;
  initialValue: string;
  multiline?: boolean;
  onSubmit: (newValue: string) => void;
  onCancel: () => void;
}> = ({ isUpdating, initialValue, multiline, onSubmit, onCancel }) => {
  const [value, setValue] = useState(initialValue);

  return (
    <EditableFieldFormLayout
      isUpdating={isUpdating}
      onClickCancel={onCancel}
      onClickSubmit={() => {
        onSubmit(value);
      }}
    >
      <TextField
        size="small"
        variant="outlined"
        value={value}
        multiline={multiline}
        minRows={multiline ? 5 : undefined}
        maxRows={multiline ? 5 : undefined}
        onChange={(event) => {
          setValue(event.target.value);
        }}
      />
    </EditableFieldFormLayout>
  );
};
```

後はこれらのコンポーネントを各renderPropsで設定することでテキスト用のインライン編集UIの完成です。`SetOptional`で`renderContent`と`renderForm`をoptionalにして渡す必要がなくなりましたが、最後に`restProps`でスプレッドしていることで、呼び出し時に指定した場合はそちらが使われるようになります。

```tsx:EditableFieldを使ったテキスト用のインライン編集UIコンポーネント
import type { SetOptional } from "type-fest";

export type EditableTextFieldProps = SetOptional<
  EditableFieldProps<string>,
  "renderContent" | "renderForm"
> & {
  multiline?: boolean;
};

export const EditableTextField: FC<EditableTextFieldProps> = ({
  multiline,
  ...restProps
}) => {
  return (
    <EditableField
      renderContent={({ value }) => <EditableTextFieldContent value={value} />}
      renderForm={({ isUpdating, value }, { submit, editEnd }) => {
        return (
          <EditableTextFieldForm
            isUpdating={isUpdating}
            initialValue={value}
            multiline={multiline}
            onSubmit={submit}
            onCancel={editEnd}
          />
        );
      }}
      {...restProps}
    />
  );
};
```

#### renderProps周りの拡張例

`renderLabel`, `renderContent`の拡張例として、未入力の時はラベルも非表示で「メモを追加」というボタンだけ表示するケースを作ってみます。renderPropsには情報が全て提供されているため、それを元に微調整するだけで実現できます。デフォルトと同じ挙動になる部分は実装済みのコンポーネントやメソッドを呼ぶだけで良く、必用最低限の変更だけで済みます。`renderForm`についてはこのケースでは変更不要なので未指定のままです。なお、折角なので`multiline`オプションをつけて複数行対応させています。

```diff tsx:未入力時は「メモを追加」ボタンだけ表示するように調整
+import { Button } from "@mui/material";
+import AddIcon from "@mui/icons-material/Add";

 const App: FC = () => {
   const [isEditMode, setIsEditMode] = useState(false);
   const [text, setText] = useState("");

   return (
     <EditableTextField
       isEditMode={isEditMode}
-      label="名前"
+      label="メモ"
       value={text}
       updateHandler={(newText) => {
         setText(newText);
       }}
       onEditStart={() => {
         setIsEditMode(true);
       }}
       onEditEnd={() => {
         setIsEditMode(false);
       }}
+      multiline
+      renderLabel={(params, actions) => {
+        // 編集中かメモがあるときのみラベルを表示する
+        if (params.isEditMode || params.value) {
+          return defaultRenderEditableFieldLabel(params, actions);
+        }
+        return null;
+      }}
+      renderContent={({ label, value }, { editStart }) => {
+        // メモが存在しない場合は追加ボタンのみ表示
+        if (!value) {
+          return (
+            <Box>
+              <Button startIcon={<AddIcon />} onClick={editStart}>
+                {label}を追加
+              </Button>
+            </Box>
+          );
+        }
+
+        // それ以外は通常と同じ表示をする
+        return <EditableTextFieldContent value={value} />;
+      }}
     />
   );
 };
```

実行すると以下のGifアニメのようになり、未入力の時だけボタンが表示され、入力されればいつものUIが出ています。

![](/images/customizable-editable-fields/example-editable-text-field-instant-custom.gif)

### 日付用のインライン編集UIの実装

同様の方法で日付入力用の`EditableDateField`も作りました。やっていることはテキスト用と同じなのでコードは折りたたみにしているため、詳細見たい方のみ開いてご覧ください。

:::details 日付用のコンテンツ表示とフォームコンポーネント

```tsx:日付用のコンテンツ表示コンポーネント
import { Typography } from "@mui/material";
import { formatDate } from "date-fns";

export const EditableDateFieldContent: FC<{ value: string | Date | null }> = ({
  value,
}) => {
  return (
    <Typography>{value ? formatDate(value, "yyyy/MM/dd") : null}</Typography>
  );
};
```

```tsx:日付用のフォームコンポーネント
import { IconButton } from "@mui/material";
import {
  DatePicker,
  type DatePickerProps,
} from "@mui/x-date-pickers/DatePicker";
import { CalendarIcon, ClearIcon } from "@mui/x-date-pickers/icons";

export const EditableDateFieldForm: FC<
  {
    isUpdating?: boolean;
    initialValue: Date | null;
    onSubmit: (newValue: Date | null) => void;
    onCancel: () => void;
  } & Pick<DatePickerProps, "referenceDate">
> = ({ isUpdating, initialValue, onSubmit, onCancel, ...restProps }) => {
  const [value, setValue] = useState(initialValue);
  const [isOpen, setIsOpen] = useState(false);

  return (
    <EditableFieldFormLayout
      isUpdating={isUpdating}
      onClickCancel={onCancel}
      onClickSubmit={() => {
        onSubmit(value);
      }}
    >
      <DatePicker
        {...restProps}
        value={value}
        open={isOpen}
        onOpen={() => {
          setIsOpen(true);
        }}
        onClose={() => {
          setIsOpen(false);
        }}
        slotProps={{
          calendarHeader: {
            format: "yyyy年MM月",
          },
          textField: {
            size: "small",
            fullWidth: true,
            readOnly: true,
            onClick: () => {
              setIsOpen(true);
            },
            slotProps: {
              input: {
                endAdornment: (
                  <>
                    {value != null && (
                      <IconButton
                        size="small"
                        onClick={(event) => {
                          event.stopPropagation();
                          setValue(null);
                        }}
                      >
                        <ClearIcon fontSize="small" />
                      </IconButton>
                    )}
                    <IconButton size="small">
                      <CalendarIcon fontSize="small" />
                    </IconButton>
                  </>
                ),
              },
            },
          },
        }}
        onChange={(newValue) => {
          setValue(newValue);
        }}
      />
    </EditableFieldFormLayout>
  );
};
```

:::

これを使って検証では生年月日を入れるケースにしたので、表示部分は年齢も出るようにカスタマイズしてみました。

```tsx:EditableDateFieldの使用例
import { formatDate, differenceInYears, addYears } from "date-fns";

const App: FC = () => {
  const [isEditMode, setIsEditMode] = useState(false);
  const [date, setDate] = useState<Date | null>(null);

  return (
    <EditableDateField
      isEditMode={isEditMode}
      label="生年月日"
      value={date}
      referenceDate={addYears(new Date(), -20)}
      updateHandler={(newDate) => {
        setDate(newDate);
      }}
      onEditStart={() => {
        setIsEditMode(true);
      }}
      onEditEnd={() => {
        setIsEditMode(false);
      }}
      renderContent={({ value }) => {
        if (value == null) {
          return <Typography color="textSecondary">不明</Typography>;
        }
        const age = differenceInYears(new Date(), value);
        return (
          <Typography>
            {formatDate(value, "yyyy/MM/dd")} ({age}歳)
          </Typography>
        );
      }}
    />
  );
};
```

### refetch中に古いデータを表示させない調整

先ほどまで見せたものは即時変更のものですが、APIを経由した非同期の場合だとrefetchまでの間に変更前のデータが表示される可能性があります。
分かりやすいように以下のGifアニメでレスポンスデータを左に表示した状態で更新してみますが、更新後にrefetchが完了するまでの間、入力したはずの文字が出ず「未入力」と表示されてしまっています。

![](/images/customizable-editable-fields/show-old-value.gif)

この問題を解決するには以下のように更新時に使用した値を保持しておき、最新のデータが返ってくるまでは保持した値を優先して出すようにします。

```diff tsx:更新直後に古い値が表示されないように保持する
 export const EditableField = function <T>({
   isEditMode,
   label,
   value,
   disabled,
   updateHandler,
   onEditStart,
   onEditEnd,
   renderLabel = defaultRenderEditableFieldLabel,
   renderContent,
   renderForm,
 }: EditableFieldProps<T>) {
   // 更新中か
   const [isUpdating, setIsUpdating] = useState(false);

+  // 更新成功した場合に、更新後の値を保持するためのstate
+  const [updatedState, setUpdatedState] = useState<{ value: T } | null>(null);

+  // 最新のデータがpropsから渡ってきたら更新時の値を保持する必要がないので、更新時の値をクリアする
+  useEffect(() => {
+    setUpdatedState(null);
+  }, [value]);

   const params: RenderEditableFieldParams<T> = {
     isUpdating,
     isEditMode,
     label,
-    value,
+    value: updatedState != null ? updatedState.value : value,
     disabled,
   };
   const actions: RenderEditableFieldActions<T> = {
     editStart: onEditStart,
     editEnd: onEditEnd,
     submit: async (newValue: T) => {
       setIsUpdating(true);
       try {
         await updateHandler(newValue);
+        setUpdatedState({ value: newValue });
         onEditEnd();
       } finally {
         setIsUpdating(false);
       }
     },
   };

   return (
     <Stack spacing={0.5}>
       {renderLabel(params, actions)}
       {isEditMode && !disabled
         ? renderForm(params, actions)
         : renderContent(params, actions)}
     </Stack>
   );
 };
```

これで動かすと以下のGifアニメのようにレスポンスがまだ未反映の状態でも更新時に使用した文字列が即表示されるようになります。

![](/images/customizable-editable-fields/keep-updated-value.gif)

:::message
検証用ではチェックボックスでこの機能をON/OFFするようにしているため、CodeSandbox上のコードでは外から`keepUpdatedValue`を受け取った実装になっており、上記のコードと少し異なっているので注意してください（デフォルトはtrueなのでそのままコピペしても上記と同じ挙動にはなります）
:::

## 終わりに

以上がインライン編集UIを拡張性が高い形で実装する方法でした。インラインであるがために表示する場所によって見せ方が微妙に違って、最悪似たような実装を何度も書く羽目になりそうでしたが、各要素ごとのrenderPropsを用意することでかなり柔軟性のある実装になったと思います。これだけ柔軟性を持ちつつも、refetch中の古いデータを表示しない処理など本質な部分はコンポーネント内部に共通化されており、同じ実装を書かずに済む構成になって個人的には大満足です。
インライン編集のUIを実装する方の参考になれば幸いです。
